## Action Types (assign exactly one per description)
- **chat**: Assign if the description involves communication with another person **AND** there are at least two communicable persons in Current Perception.
- **interact**: Assign if the description involves interacting with an object **AND** the object is visible in Current Perception.
- **move**: Assign if the description involves physical movement toward another place or object.
- **think**: Assign if none of the above conditions are satisfied.

---

For each description:
1. Identify the target object or person.
2. Check if the target is visible in Current Perception.
3. If the target is visible, assign accordingly.
4. If not visible, assign **think**, regardless of the description content.

After initial assignment:
- For each action, verify:
  - If interact or chat is assigned, is the target actually visible according to Perception?
- If not, revise the action to **think**.

- You **must not infer** the existence of any object or person not in Current Perception.
- If there is any conflict between natural language intuition and Perception validation, **Perception validation takes absolute priority**.
